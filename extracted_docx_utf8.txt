
Complete Service Pricing Specification
Developer & Admin Reference Document — All Rates Admin-Editable
Covers: Hourly Rental · Intercity (One-Way & Round-Trip) · Corporate Transport · Airport Transfer · Travel & Tour
Document Scope
This document consolidates the pricing calculation logic for all five currently finalized Rownaa services into a single developer reference: Hourly Rental, Intercity Travel (One-Way & Round-Trip), Corporate Transport, Airport Transfer, and Travel & Tour. It replaces the need to reference three separate files (Hourly Pricing Developer Spec, Intercity Pricing Specification, and Service Pricing Formula Specification) — all of that content is merged here without changes to the underlying logic.
Event Transport and Wedding Booking pricing are intentionally excluded — that formula is still under review and will be issued as a follow-up specification once finalized.
Note: Every rate, threshold, and percentage in this document must be implemented as an admin-editable setting. Nothing described below should be hard-coded in the application.

1.2 Pricing Logic
1.2.1 Base Package
Each category has two selectable base packages: 4-Hour and 10-Hour.
The 4-Hour and 10-Hour rates already include a fixed included distance (recommended default: 40 km) and driver cost.
The included-distance value (40 km) must also be an admin-editable field, per category if needed.
1.2.2 Extra Hour Charge
If the customer keeps the car beyond the selected package duration, each additional hour is charged at the category's Extra Hour Rate.
Extra hours should be calculated by rounding up to the nearest full hour (e.g. 1 hour 10 minutes over = 2 extra hours). Its also also be an admin-editable field.
If the trip distance exceeds the included distance (default 40 km) within the booked package, each additional kilometre is charged at the category's Extra KM Rate.
Extra KM and Extra Hour charges apply independently and are both shown as separate line items to the customer and driver — never merged into a single total.
1.3 Admin Panel Requirements
A dedicated 'Hourly Pricing' settings screen where every cell in the 1.1 table (4-Hour Rate, 10-Hour Rate, Extra Hour Rate, Extra KM Rate) can be edited independently, per category.
Ability to add a new vehicle category (name + seat count + all four rate fields) without a code change.
Ability to edit the included distance (default 40 km) globally or per category.
All rate changes should take effect immediately for new bookings, without affecting bookings already confirmed.
Keep a simple change log (who changed which rate, old value, new value, timestamp) for accountability.

2.3 One-Way Trip Pricing
Steps: (1) customer picks Pickup, Drop and car category → (2) system calls the map API for road distance = Planned Distance → (3) system looks up Base Fare + Per-KM Rate for that category from Admin settings → (4) calculates Total Price → (5) customer sees only the Total → (6) once the trip runs, Actual Distance is tracked against Planned Distance for Extra-KM (Section 2.5).
Total Price = Base Fare + (Planned Distance × Per-KM Rate)
Distance is always pulled live from a map/distance API (e.g. Google Maps Distance Matrix) — road distance, never straight-line, never typed in manually.
Customer only ever sees the final Total Price (e.g. "৳10,680") — per-km rate and base fare are never shown or broken down. Route distance may optionally be shown for information only.
Worked example — Dhaka → Jessore, ≈192 km, Economy:
3,000 + (192 × 40) = 10,680 Tk
2.4 Round-Trip Pricing
A round trip is priced differently depending on whether the car waits overnight, since a waiting car can't take other bookings.
Type
Description
Same-Day
Car drops customer, waits a few hours nearby, returns same day. No overnight stay.
Multi-Day
Car & driver stay at the destination one or more nights before returning.
2.4.1 Same-Day Round Trip
Same-Day Price = One-Way Price + (Base Fare × Same-Day Return Charge %, default 50%)
One-Way Price part uses the one-way distance, not doubled — the Per-KM Rate already covers the return drive.
Same-Day Return Charge % is its own admin field (2.6); being a % of Base Fare it auto-scales by category.
Must always be shown to the customer as its own line item, separate from the One-Way Price.
Maximum Same-Day Round Trip Distance: admin-editable, default 250 km (one-way). Beyond this, Same-Day is not offered — only Multi-Day is available (fatigue/safety limit).
2.4.2 Multi-Day Round Trip — Waiting Charge
Multi-Day Price = One-Way Price + (Waiting Nights × Daily Waiting Charge)
Daily Waiting Charge is its own admin-editable rate (Tk/night); can become category-specific later.
Always shown to the customer as its own line item, separate from the trip price.
If the customer changes the number of waiting nights before the trip starts, recalculate and show the new total before charging.

2.4.3 What the Customer Sees
Pickup Point, Drop Point, car category and trip type (Same-Day / Multi-Day) are selected at booking; Multi-Day also asks for number of nights. Breakdown shown: Trip Fare + Waiting Charge (if any) = Total. No per-km rate or base fare shown.
2.4.4 Worked Examples (Economy)
Dhaka → Jessore, ≈192 km (within the 250 km limit, both types available):
Same-Day: 10,680 + (3,000 × 50%) = 12,180 Tk   |   3-day/2-night: 10,680 + (2 × 2,000) = 14,680 Tk
Dhaka → Cox's Bazar, ≈414 km (exceeds 250 km → only Multi-Day offered), 3-day/2-night:
3,000 + (414 × 40) + (2 × 2,000) = 23,560 Tk
2.5 Extra Distance (Overage KM) — Applies to Both Trip Types
Planned Distance: One-Way = Pickup→Drop distance. Round-Trip = one-way distance × 2 (out + back).
"Start Trip" begins GPS tracking of Actual Distance; "End Trip" / "Complete Trip" closes it and compares Actual vs. Planned.
If Actual > Planned, the difference is Extra KM. If Actual ≤ Planned, Extra KM = 0.
Extra Charge = Extra KM × Extra-KM Rate     New Total = Original Total + Extra Charge
Extra-KM Rate (Tk/km) is its own admin field, separate from the normal Per-KM Rate.
Extra Charge is always its own line item — never merged silently into the trip total.
Visible to the driver (after End Trip: Extra KM, Extra Charge, new grand total) and to admin, per completed trip: Planned Distance, Actual Distance, Extra KM, Extra Charge, New Total, plus (for multi-day) Waiting Nights and Waiting Charge.
Global ON/OFF toggle in Admin Panel. OFF: distances are still recorded for reporting, but nothing extra is charged. ON: Extra Charge is auto-calculated as above.
Any time the driver is asked to use the car for personal use while waiting overnight, that distance is out of scope and is not billed to the customer unless agreed separately.

2.7 Developer Checklist
Planned Distance always comes live from the map API (road distance) — never typed in manually.
One-Way Total = Base Fare + (Planned Distance × Per-KM Rate).
Before offering Round-Trip options, check one-way distance against Max Same-Day Distance (default 250 km): if it's over, only offer Multi-Day. Its work only when one-way distance against Max Same-Day Distance(ON)
Same-Day Price = One-Way Price + (Base Fare × Same-Day Return Charge %); Multi-Day Price = Same-Day Price + (Waiting Nights × Daily Waiting Charge).
Round-trip Planned Distance for overage tracking = one-way distance × 2; use the same Start Trip / End Trip GPS tracking and Extra-KM formula as One-Way, gated by the same ON/OFF toggle.
Base Fare, Per-KM Rate, Extra-KM Rate, Same-Day Return Charge %, Max Same-Day Distance and Daily Waiting Charge are each their own separate, admin-editable field — never hard-coded, never shared with each other.
Every car category on the Choose Car screen has its own Admin ON/OFF toggle, independent of pricing-tier toggles.
Customer-facing screens show only the final Total Price plus clearly separate line items for Same-Day Return Charge / Waiting Charge / Extra Charge — the raw per-km rate or base fare is never shown.
If the customer changes waiting nights before the trip starts, recalculate and show the new total before charging.
Two pricing tiers (Economy, Premium) active at launch; structure so Luxury and further car categories can be switched on later without rebuilding the pricing engine.

4. Airport Transfer
Short point-to-point trips between Hazrat Shahjalal International Airport and a pickup/drop zone. Priced as a flat zone fare, not per-km, matching standard market practice.
4.1 Formula
Airport Transfer Fare = Flat Zone Fare (by zone + car category) + Waiting Charge (depends on Trip Direction, beyond free window) + Round Trip Surcharge (if applicable) + Late Night Surcharge (if applicable)
Note: Trip Direction (Section 4.5) determines which Waiting Charge window applies and whether the Round Trip Surcharge is added — this must be captured at booking time, not assumed from the zone or car category.
4.2 Car Categories
Same car category set used across the platform, excluding "Chander Gari" (Intercity-only).
Sedan Economy, Sedan, Sedan Premium, Noah, HiAce

4.6 Waiting Charge
Waiting Charge has two separate windows depending on Trip Direction (4.5). Only one applies per leg — never both on the same leg.
4.6.1 Send-off Window (Airport Drop-off leg)
Applies when the driver/family is at the airport waiting for the departing passenger to finish check-in/security (Airport Drop-off or the drop-off leg of a Round Trip).
Free wait window: 30 minutes from arrival at the airport (admin-editable).
After the free window: admin-editable hourly waiting charge (market range observed: Tk 100–200/hour).


4.6.2 Receive Window (Airport Pickup leg)
Applies when the driver is waiting at the airport for an arriving passenger to clear immigration/baggage (Airport Pickup or the pickup leg of a Round Trip).
Free wait window: 30 minutes for domestic flights, 60 minutes for international flights, counted from actual flight landing time — not scheduled time (admin-editable).
After the free window: admin-editable hourly waiting charge (market range observed: Tk 100–200/hour).
Flight number should be captured at booking so the system/driver can track real landing time (flight delays should not cost the customer extra free-window minutes).
4.7 Round Trip Surcharge
Applies whenever a single booking covers both an Airport Drop-off leg and an Airport Pickup leg (Trip Direction = Round Trip, Section 4.5) — e.g. a family drops a traveler off, then returns later to receive them, or the common send-off-and-receive pattern for a family member going abroad and coming back.
Flat admin-editable surcharge added on top of the one-way Zone Fare (market range observed: Tk 500). This is separate from, and in addition to, the Waiting Charges in Section 4.6.
Not applied to Airport Drop-off-only or Airport Pickup-only bookings.
4.8 Late Night Surcharge
Admin-editable flat surcharge for duty between 1:00 AM–5:00 AM (market range observed: Tk 300).





5. Travel & Tour
Multi-day tour packages to popular destinations (Cox's Bazar, Sylhet, Sreemangal, etc.). Unlike Intercity, this is NOT calculated from distance × per-km — it is sold as a fixed all-inclusive package per route, matching standard market practice.
5.1 Formula
Tour Fare = Fixed Destination Package Rate (by route + car category + number of days) + Extra Day Charge (if extended) + Custom Route Fallback (if no fixed package exists)

5.3 Package Inclusions
Package rate includes: rental fare for all days, driver food & accommodation for the trip duration, fuel, CNG, tolls, and all standard road expenses on the defined route.
If the customer wants to visit places outside the defined route, the customer bears any extra fuel cost for that detour (flag this clearly in the booking confirmation UI).
5.4 Extra Day Charge
If the customer extends the trip beyond the booked number of days, each additional day is charged at the category's standard Daily Rate (reuse the Daily rate from the Hourly Rental Pricing section, 1.1).
5.5 Custom Route Fallback
If the customer requests a destination with no pre-defined fixed package, the system falls back to the Intercity + Round Trip formulas (Sections 2.3 / 2.4) to generate a quote instead of blocking the booking.
